# Architecture

| Module | Package | Role |
|--------|---------|------|
| ads-core | com.example.adlib.core | SDK-independent logic + ads-mobile-sdk 1.7.0 + UMP + coroutines. No View/Compose. |
| ads-ui-compose | com.example.adlib.ui.compose | Compose native/banner helpers. Depends on ads-core. |
| ads-testing | com.example.adlib.testing | Fakes (AdGateway, consent, clock, foreground). Depends on ads-core. |
| sample | com.example.adlib.sample | Demo app. |

Design: `docs/ads-lib-phase1-v3.txt` (v3 wins). History: `docs/history/`. Work board: `docs/TASKS.md`.
Current code:
- `core.config`: `PlacementConfig` (+ `AdTiers`, `HighFloorTier`, `AdUnitTier`, `RefreshConfig`, `PlacementDefault`) and internal `ConfigParser` (new schema, design section 3; warnings via `ConfigWarningSink`).
- `core.consent`: `ConsentSource` (UMP isolation; load and show of the form are separate so the 10s timeout never covers the form on screen), `UmpConsentSource`, `ConsentGate` (process-level `canRequestAds` / `privacyOptionsRequired` / `formShowing` StateFlows, single-flight `gather`, late UMP answers still refresh; `onActivityDestroyed` ends a form whose host died without a dismiss with `HOST_DESTROYED`, wire it from `AppActivityTracker.addDestroyedListener`).
- `core.bootstrap`: `SdkInitializer` + `MobileAdsInitializer` (worker thread, app id from manifest), `AdsBootstrap` (init once on first `canRequestAds == true`, config wait 8s from T0, `awaitReadyToLoad()` = false at once without consent, 4s per waiter for init).
- ads-testing: `FakeConsentSource`, `FakeSdkInitializer` (manually driven).
- `core.placement`: `Placement`, `PlacementRegistry` (rejects duplicate names / poolKey with two formats: throws when strict, else warns and skips).
- `core.state`: `ConfigProvider` (read on every lookup), internal `AdsState` (Premium flow, kill switch, `config(placement)`, `isAdAllowed` = one gate for load and show).
- `core.events`: `AdsEvent`, `AdsEventListener`, internal `AdsEventBus` (delivers on the serial dispatcher, swallows listener exceptions; `observe` lets lib features see the same events, e.g. App Open click skip).
- `core.pool`: internal `AdPool` (v3 6.1/6.3) keyed by (poolKey, format), state confined to the serial scope. Waiter-driven: min(uncovered waiters, per-format permits) loads at once; a load = `awaitReadyToLoad` -> fresh config -> high floor (preload with no waiter, not native, 30s cap, abandoned when a waiter arrives) -> normal tiers within `total_timeout_ms`; result -> oldest waiter, else pool, else `Dropped(late)`; a load with no ad answers one waiter with NoAd. Full key: a high-floor arrival evicts the oldest normal (`Dropped(capped)`). Expiry by `Clock` (app open 4h, others 55 min); Premium flushes. Defaults `PoolOptions`: maxPerKey 2, 3 loads per format (old lib).
- `core.testmode`: `RevenueStore` (app persistence), internal `TestMode`. Rule (ported from old `TestAdGuard`): test mode = a native with "Test Ad" headline was seen OR paid events were seen but no currency has a positive total; fresh install = not test mode. Totals are per currency. R27b: no paid event yet => native hidden until first paid impression (`AdsEvent.HiddenOnPurpose`). `MobileAdsInitializer(testDeviceIds)` sets RequestConfiguration before init. ads-testing: `FakeRevenueStore`.
- `core.fullscreen`: internal `FullScreenGate` (v3 6.2/6.4) Idle -> Reserved(owner) -> Showing(owner) -> Idle; only the holder (identity) moves it, so a late dismiss never frees the next owner. Watchdog from `show`: freed on the next non-ad app Activity ON_RESUME counted AFTER the show, or after 2 min (`FullScreenGateOptions.watchdogMs`); emits `WatchdogFired` and tells the owner. `closed` (ad dismissed) and the watchdog start `minGapAfterFullScreenMs` (60s, queried via `isWithinGap`, checked by interstitial/App Open); `release` (no ad / show failed) does not. Premium on while Reserved frees it. `ActivityTracker` (public) = counter of non-ad app resumes + `resumedActivity` (top non-ad Activity, weak); `ForegroundSource` (public) = any Activity incl. ads STARTED, rotation is not background; `AppActivityTracker.of(application)` = the ONE per-process implementation of both (ad Activity = SDK package prefix). ads-testing: `FakeActivityTracker`, `FakeForegroundSource`.
- `core.fullscreen.interstitial`: internal `InterstitialController` (`preload`, `showThen` returns its Job; the action runs exactly once in every branch, waits for a STARTED app Activity if the host is dead; gate reserved before the ad wait and released on every non-Showing path; recheck of `isAdAllowed`/gone/expiry/host right before show; failed preload retried after 5s then 15s via `AdPool.addPreloadFailedListener`). `InterstitialCaps` (dailyCap, interval via `TestMode.effectiveInterstitialIntervalMs`, oneInN; day boundary by `Clock` + TimeZone) persisted through `CapStore` (app persistence like `RevenueStore`; `InMemoryCapStore`). `ActivityTracker.startedAppActivities` = non-ad Activities currently STARTED.
- `core.fullscreen.rewarded`: internal `RewardedController` (`preload`, `request` returns its Job, `isAllowed`/`isAvailable` live flows sampled every 1s on the serial scope; `AdPool.hasFreshAd` is the read-only probe). Per request exactly one terminal callback: `onUnavailable` (nothing shown) or `onClosed` (shown; `onEarned` first if earned), via one idempotent `Request.end()`. Gate Reserved during the 10s ad wait (waiting screen), released on every non-Showing exit; ignores the gap and caps; `gone_in_test_mode` not applied (Q-C).
- `core.appopen`: `AppOpenOverlay` (public, drawn by T8: covers one host, blocks Back, removes itself on host stop/destroy) and internal `AppOpenResumeController` (v3 7): `attachResume` (first foreground = launch), skips a return after any `AdsEvent.Clicked`, while `formShowing`, within `pauseForExternalFlow` (one return, expires), away < `minBackgroundMs`, not allowed, gate busy, gap, excluded top Activity. Shows only once the top Activity is RESUMED (else the host's onResume trips the gate watchdog); first try of the process = reactive load under the overlay within min(`reactiveShowTimeoutMs` 5s, `overlayMaxMs` <= 15s), late ad stays cached; then armed: cached only, else silent preload; preload one at each show. ads-testing: `FakeAppOpenOverlay`.
- `core.nativead`: `NativeAdSource` (public, for the UI modules; `Ads.install` provides it, T11) and internal `NativeController`: `request(placement) { ad? -> }` runs in the lib scope (never cancelled, so an arrived ad is never lost), waits for the pool at most `total_timeout_ms`, rechecks `isAdAllowed` + R27b on arrival, destroys anything not handed over in one `finally`, sets paid/click/impression listeners (paid feeds `TestMode`). ads-testing: `FakeNativeAdSource`.
- ads-ui-compose `ui.compose.nativead`: `NativeComposeUtility.kt` (Google Next-Gen compose_utils, Apache-2.0, modified: see its header, `/NOTICE`, `licenses/`), `NativeAd(placement, adIndex, loading) { ad -> }` (content inside the SDK NativeAdView), `NativeAdLarge`/`NativeAdSmall` (+ `*Content`, `*Placeholder` of the same fixed size), `LocalNativeAdSource`. Internal `NativeSlotHolder` in a ViewModel of the current ViewModelStoreOwner (NavBackStackEntry): slots keyed (placement, adIndex), Idle | Loading | Shown | Gone, load on first visible, Gone sticky, cap max(8, visible + 1) checked when a slot starts loading, LRU of last visible released (destroy -> Idle), `onCleared`/Premium destroy all; stale answers released.
- `core.banner`: `BannerAdSource` (public, for UI modules; `Ads.install` provides it, T11) and internal `BannerController`: direct load per request (no pool): `awaitReadyToLoad` -> fresh config -> normal tiers each within its timeout, all within `total_timeout_ms`; late/unused ads destroyed; paid/click/impression to TestMode + event bus (click feeds App Open skip). ads-ui-compose `ui.compose.banner`: `BannerAd(placement)` (width-aware anchored adaptive, draws nothing until loaded) + internal `BannerSlot` (Loading | Shown | Gone, destroy on dispose/Premium), `LocalBannerAdSource`.
